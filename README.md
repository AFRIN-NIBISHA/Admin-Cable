# SkyLink Cable TV - Administrative Operations Console

A premium, elegant React-based administrative console designed for regional cable TV operators to manage subscriber databases, SaaS packages, payments, maintenance schedules, support tickets, and performance analytics.

The interface is styled with a highly professional **Gold and Cream Warm Theme** (matching elegant institutional layouts) with serif headlines, smooth transitions, and high-fidelity custom select components.

---

## ✨ Features

- **Dashboard**: Real-time business logs, dynamic collection performance indicators, and monthly billing graphs.
- **Operators Management**: Complete CRM directory for sub-operators, license parameters, and coverage regions.
- **Subscription Packages**: Configure SaaS service tiers, pricing levels, and operator limit thresholds.
- **Payment Ledger**: GST tax invoices generator, manual transaction logger, and GST settlement books.
- **Customer Analytics**: Dynamic customer state splits and operator regional customer distributions.
- **Notifications Dispatcher**: Direct announcements hub for SMS and WhatsApp API gateways.
- **Support Complaint Tickets**: Queue assignee tracker and operator message threads.
- **System Configs**: Webhook controls, Twilio/Meta API endpoints, and database security snapshot settings.

---

## 🎨 Design System & Highlights

- **Gold & Cream Palette**: Rich gold accents (`#b8974a`), soft warm cream backgrounds (`#faf8f5`), and dark stone typography.
- **Top Horizontal Menu**: Fully horizontal top navigation with a gold sliding hover underline and active indicators.
- **Elastic Transitions**: Cards lift and scale with an elastic spring animation on hover using a customized cubic-bezier curve.
- **Custom Selects**: Native select dropdown lists replaced with customized, gold-accented overlay dropdown elements.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16.0 or higher)
- npm (v8.0 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AFRIN-NIBISHA/Admin-Cable.git
   ```

2. Navigate to the client directory:
   ```bash
   cd Admin-Cable/Client
   ```

3. Install project dependencies:
   ```bash
   npm install
   ```

4. Start the local development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173/`.
